## Documentation Types

Each file in the repository has two types of documentation:

1. **`<filename>_docs.md`** - Comprehensive documentation including:
   - Full source code
   - Detailed analysis
   - Function and class documentation
   - Usage examples

2. **`<filename>_kw.md`** - Keyword index with:
   - Extracted identifiers
   - Function and class names
   - Type definitions
   - Links to documentation

Each folder also has:

- **`index.md`** - Directory listing with links to all files
- **`doc.md`** - Narrative overview of the folder's purpose
- **`sub.md`** - Merged keyword index for the folder
